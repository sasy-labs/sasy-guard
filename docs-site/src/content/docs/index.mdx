<Aside type="tip" title="The quickest way: let your agent set it up">
Install the setup skill, then ask your coding agent to **set up Sasy Guard**:

```bash
npx skills add -g sasy-labs/sasy-guard
```

The agent checks the requirements, installs the runtime, adds the guard to
itself, and tells you how to test it. Each agent's page below has the
steps by hand.
</Aside>

## Supported Agents

Sasy Guard checks each action a coding agent is about to take, such as running a
command or editing a file, before the action runs. It works with these agents:

<CardGrid>
  <LinkCard
    title="Claude Code"
    description="A plugin you can set up in minutes, or a mod for deeper integration."
    href="/claude-code/"
  />
  <LinkCard
    title="pi"
    description="An extension that checks every tool call pi makes."
    href="/pi/"
  />
  <LinkCard
    title="Codex CLI"
    description="A hook that checks every tool call Codex makes."
    href="/codex/"
  />
</CardGrid>

All three use the same policy engine and the same policy. Each agent connects
to the engine through a small adapter: a piece that translates the agent's tool
names and its saved conversation history into one shared format the engine
reads. Supporting another agent means writing one more adapter, not changing
the engine or the policy.
